
# PaperLens

PaperLens is an AI-powered academic research paper analyzer built with Python and Streamlit.

## Features

- Upload academic research papers in PDF format.
- Extract and process PDF text.
- Generate a three-bullet research summary.
- Extract important concepts using NLP.
- Visualize semantic relationships using an interactive concept graph.
- Export summaries and analysis results.

## Technologies

- Python
- Streamlit
- PyMuPDF
- Sentence Transformers
- NetworkX
- PyVis

## Run locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python -m streamlit run app.py
```
